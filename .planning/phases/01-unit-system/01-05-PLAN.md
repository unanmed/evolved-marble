Create `src/common/rng.ts` (per AGENTS.md convention #9 — general reusable abstractions live in `src/common/`; D-07/D-09/D-10). Import `IRng` from `@/common/types`.

- `export class MathRng implements IRng` — a JSDoc'd class whose `next()` method returns `Math.random()`. JSDoc must state this is the default (non-deterministic) source; the abstraction exists only to inject fixed sequences in tests (D-07).
- `export function sampleNormal(rng: IRng, mean: number, sd: number): number` — JSDoc'd. Implement Box–Muller: draw `u1 = rng.next()` and, while `u1 <= 0`, keep drawing (guard against `Math.log(0) = -Infinity`); draw `u2 = rng.next()`; compute `z = Math.sqrt(-2 * Math.log(u1)) * Math.cos(2 * Math.PI * u2)`; return `Math.max(0, mean + z * sd)` (clamp to non-negative, D-08). Include a comment noting that with σ = mean/8 the clamp is a correctness guard, not a shaping mechanism.

Then create `tests/units/rng.test.ts` asserting the `<behavior>` cases.
