Growth-model note (OQ-2 RESOLVED — encode the distinction in the `IClassDef` field JSDoc; the formulas themselves are applied in `Unit.getAttribute`, plan 01-04):
- `attackGrowth` is the **level-scaling coefficient k** in the attack-growth `k·L` form — the per-level increment scales with the current level, so attack growth is super-linear. JSDoc it as such on each `IClassDef.attackGrowth` value.
- `defenseGrowth` is a **flat per-level increment** (`+defenseGrowth` each level, constant), NOT a `k·L` curve — 防御 is a percentage damage-reduction stat and a level-scaled curve would over-scale late-game mitigation. JSDoc it as such on each `IClassDef.defenseGrowth` value.
- Do NOT store a per-class copy of the growth *formula* here — only the coefficients are data; the shape lives in `getAttribute`.
