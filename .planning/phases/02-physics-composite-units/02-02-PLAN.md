<objective>
Prove the whole physics architecture end-to-end on one thin slice, then wire it into the sim core and build out the full composite factory. A composite unit (body + armor on one body, weapon as a separate revolute-jointed body) steps under Rapier, its pose mirrors into the EntityStore, a weapon-vs-armor contact surfaces as a typed part-tagged event, and the same-seed double-run stays deterministic.

Purpose: PHYS-01 (compound, part-tagged bodies), PHYS-02 (typed contact events), PHYS-03 (deterministic build + green fingerprint). The tracer de-risks the highest-uncertainty item first (headless Rapier + composites + pre-step Δv + determinism), then expansion builds out from the proven slice.

Output: `physics-world.ts`, `composite.ts`, `contact.ts`, extended `events.ts`/`entity-store.ts`/`world.ts`/`battle-sim.ts`/`snapshot.ts` (v3), and the physics gate + composite + CCD tests.
</objective>

| Rapier `EventQueue` → `ContactBridge` | Handles from the physics engine index a project-owned map; an unregistered handle must resolve to `null`, never dereference `undefined`. |

| `snapshot()`/`restore()` bytes | In-process only this phase (D-34); `restoreSnapshot` accepts only bytes this process produced. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
