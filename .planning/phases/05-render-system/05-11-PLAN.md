1. In `src/control/constants.ts` add typed, JSDoc'd constants (AGENTS §6):
   - `DEFAULT_AI_STALL_SPEED_THRESHOLD` (default 0.5 m/s) — closing speed below this counts as blocked.
   - `DEFAULT_AI_STALL_DECISIONS` (default 4 decisions ≈ 24 ticks) — consecutive stalled decisions before disengaging.
   - `DEFAULT_AI_DISENGAGE_TICKS` (default 30 ticks ≈ 0.5 s) — how long the back-off lasts.
   - `DEFAULT_AI_DISENGAGE_SPEED` (default 8 m/s).
   - `DEFAULT_AI_DISENGAGE_LATERAL_WEIGHT` (default 0.6) — lateral component mixed into the back-off so the unit does not simply grind straight backwards.
2. In `src/control/DefaultUnitAI.ts` add private state: stall decision counter, disengage-until tick, and the last chosen lateral sign. All decision-tick based (use `observation.tick`), no wall clock, no RNG.
3. In `decide()` after the low-health branch:
   - Compute `towardX/towardY` (unit vector to target) and closing speed `vx*towardX + vy*towardY`.
   - If `observation.tick < disengageUntilTick`: return an action away from the target plus the stored lateral direction at `DEFAULT_AI_DISENGAGE_SPEED` (no skill intent that frame).
   - Else, if inside attack range and closing speed < threshold: increment stall counter; otherwise reset it to 0.
   - When the counter reaches `DEFAULT_AI_STALL_DECISIONS`: reset the counter, set `disengageUntilTick = observation.tick + DEFAULT_AI_DISENGAGE_TICKS`, choose lateral sign deterministically (e.g. `unitId % 2 === 0 ? +1 : -1`), and return the back-off action for this decision too.
   - Otherwise keep the existing attack-charge behaviour and skill intent.
4. Keep `torqueToward` aiming at the target during the charge; during disengage aim away/tangentially as the returned force dictates.
