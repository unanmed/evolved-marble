<objective>
Fix the UAT-observed camera behaviour:
1. On battle end, the camera currently pans to the map centre at battle zoom and then shrinks. It must pull straight back to panorama in one motion.
2. The camera is too jumpy while a battle grows; weight the in-battle follow by the sum of participant levels so bigger fights settle faster.
</objective>

<context>
User decisions (2026-10-24): weight applies only to in-battle follow; entry freeze + 0.8 s/0.2 s choreography stays fixed; pull-back must be direct.
Current exit path uses the same two-phase code as entry, which is why the camera visibly travels to the map centre first.
</context>
