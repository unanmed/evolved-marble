Create `src/render/GeometryUnitView.ts` first, exporting `class GeometryUnitView implements IUnitView`. Import `Container`, `Graphics` and `GraphicsContext` as values from `pixi.js`; import `IUnitViewState`/`IUnitViewSpec` as types from `@/render/types`. Private JSDoc'd fields: `spec: IUnitViewSpec` (readonly), `root: Container` (readonly), `rotator: Container` (readonly), `body: Graphics` (readonly), `flashRing: Graphics` (readonly), `flashColor: number` (readonly). Constructor `(spec, root, rotator, body, flashRing, flashColor)` simply assigns them. Methods:

- `getRoot(): Container` returns `root`.
- `apply(state: IUnitViewState): void` sets `root.position.set(state.x, state.y)`, `rotator.rotation = state.angle`, `root.visible = state.visible`, `body.tint = state.flash ? flashColor : spec.visual.factionColor`, and `flashRing.visible = state.flash && state.visible`. Nothing is rebuilt.
- `destroy(): void` calls `root.destroy({ children: true })` only. It must not pass the option that would destroy the shared contexts, and must not touch the other views.

Create `src/render/UnitViewFactory.ts` exporting `class UnitViewFactory implements IUnitViewFactory`. Imports: `Container`, `Graphics`, `GraphicsContext` as values from `pixi.js`; `IRenderConfig`, `IUnitView`, `IUnitViewFactory`, `IUnitViewSpec` as types from `@/render/types`; `WeaponKind`, `ArmorKind` as values from `@/units/types`; `FLASH_RING_OFFSET_METERS` from `@/render/constants`; `GeometryUnitView` from `@/render/GeometryUnitView`.

Private JSDoc'd fields: `config: IRenderConfig` (readonly), `bodyContext: GraphicsContext`, `flashContext: GraphicsContext`, `weaponContexts: Readonly<Record<WeaponKind, GraphicsContext>>`, `armorContexts: Readonly<Record<ArmorKind, GraphicsContext>>`, `disposed: boolean`.

Constructor builds every context exactly once, using `config.geometry` (never literal numbers) and `config.palette`:

- Body: a filled circle at the origin with radius `geometry.bodyRadius`, filled white (`0xffffff`) so the faction tint works. Add a thin darker outline for contrast.
- Flash ring: a stroked circle at `geometry.armorRadius + FLASH_RING_OFFSET_METERS` with the palette flash colour, initially hidden by the view.
- Each weapon context draws a grip from the body edge to the weapon centre plus a silhouette around local x = `geometry.weaponOffsetX`, with the long axis along local y and extent `geometry.weaponHalfLength`; fill with `palette.weapon` and give each kind a distinguishable silhouette: Longsword — long thin blade with a perpendicular crossguard; Shortsword — a shorter, wider blade; Axe — a thin shaft with an asymmetric head at the +y end; Hammer — a thin shaft with a thick rectangular head at the +y end; Bow — a shallow arc polyline plus a string line, no thick blade; Spear — a thin shaft extending past the half-length with a pointed tip. Use `circle`/`rect`/`poly` shape calls followed by `fill`/`stroke` (the v8 order).
- Each armour context draws over the body: Helmet — a concentric stroked ring near `geometry.armorRadius` with a small filled dome at the forward (+x) side; Shield — a thick filled arc/segment on the forward (+x) side, clearly heavier than the helmet ring. Fill/stroke with `palette.armor`.

`create(spec: IUnitViewSpec): IUnitView` builds one `Container` root, one child `Container` rotator, a `Graphics` for the body (tinted `spec.visual.factionColor`), a `Graphics` for the weapon when `spec.visual.weapon` is defined, one `Graphics` per entry in `spec.visual.armors`, and a hidden flash-ring `Graphics`; it adds the rotator to the root, the body/weapon/armour graphics to the rotator, and the flash ring to the root (so it never rotates), then returns `new GeometryUnitView(spec, root, rotator, body, flashRing, config.palette.flash)`. Only `Container` composes children; `Graphics` instances are leaves.

`dispose(): void` returns immediately when `disposed`, sets `disposed`, then destroys each shared context exactly once (body, flash, the six weapon contexts, the two armour contexts) and clears the records.

Then verify with `pnpm typecheck`. Do not draw the level number or health bar here (they belong to the HUD layer), and do not read any simulation data.
