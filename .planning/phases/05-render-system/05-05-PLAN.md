Export and JSDoc six functions:

1. `healthRatio(health: number, maxHealth: number): number` — 0 when either value is non-finite or `maxHealth <= 0`; otherwise `clamp(health / maxHealth, 0, 1)`.
2. `registerDamage(timers: IHudTimers, events: readonly IRenderDamageEvent[], frameIndex: number, outputFps: number, seconds: number): void` — compute `frames = max(1, round(max(0, outputFps) * max(0, seconds)))` once; for each event, delete the defender's entry when `event.killed`, otherwise set `visibleUntil[defenderId] = frameIndex + frames` (overwrite, never accumulate).
3. `isHealthVisible(unitId: number, timers: IHudTimers, frameIndex: number, totalUnits: number, alwaysVisibleBelowUnits: number): boolean` — return true when `totalUnits < alwaysVisibleBelowUnits`; otherwise `until !== undefined && frameIndex < until`.
4. `computeHudScale(cameraScale: number, config: IHudConfig): number` — return 1 for non-finite/non-positive `cameraScale`; `t = smoothstep(config.worldScaleAt, config.screenScaleAt, cameraScale)`; `screenFactor = (config.screenBarWidthPx / config.barWorldWidth) / cameraScale` (guard non-finite → 1); return `lerp(1, screenFactor, t)`.
5. `pruneTimers(timers: IHudTimers, liveUnitIds: readonly number[]): void` — build a `Set` of the live ids once and delete every `visibleUntil` key that is not present.
6. `computeShakeImpulsePx(events: readonly IRenderDamageEvent[], effects: IEffectsConfig, camera: ICameraConfig): number` — return 0 when no event is `killed` and the maximum finite `damage` is below `effects.shakeDamageThreshold` (a non-finite/negative threshold counts as 0, so any hit shakes); when triggered, return `clamp(max(1, maxDamage / threshold), 1, 3) * camera.shakeAmplitudePx`, coerced finite.

Do not clamp the returned impulse to `shakeAmplitudePx` itself: the camera clamps the accumulated amplitude, and the 1–3 multiplier is the intended "harder hit, stronger kick" shape. State this in the JSDoc so the division of responsibility with 05-03 is explicit.

|----------|-------------|
| physics damage events → battle sink → render tap | Only the inner sink's decision plus observed HP change is trusted evidence of an applied hit. |
