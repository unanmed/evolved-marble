<objective>
Give the viewer time to read the battle result: after a battle ends, stay at 1× for ~3 s, pull back to the panorama, and only then resume 24× peace speed.
</objective>

<context>
Today `KingdomWorld.tick` picks 1× only while a battle is active, so the very next frame after the end jumps to 24 substeps. The runner clears the camera target immediately when no active battle exists, so the pull-back starts during that jump.
`Renderer.collectTargetPoints` resolves the target battle from the active list, so a retained target id would otherwise fall back to strategies immediately.
</context>
