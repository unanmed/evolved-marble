## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator clicks → world orders | Panel input becomes simulation commands through `issueOrder`. |
| scenario/faction names → DOM | Names originate in code tables but are still rendered as text. |
| browser page → captured video | The canvas is the only video surface; DOM must stay outside it. |
| URL → demo selection | `location.search` selects a scenario variant. |
| npm scripts → build output | The build must bundle the pinned Pixi without weakening checks. |
