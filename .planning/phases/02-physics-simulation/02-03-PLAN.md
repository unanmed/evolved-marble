Create `src/physics/damage.ts`: a pure-math module (no Rapier import, no class, no state). Import `sampleNormal` from `@/common/rng`, the `IRng` type from `@/common/types`, and the `ColliderPart` type/enum from `@/physics/types`. Every function and the top-level const carry JSDoc (AGENTS §4/§6). Keep other comments sparse.

Exports:

- Top-level JSDoc'd const `DAMAGE_JITTER_SIGMA_DIVISOR = 20` — the spec's σ = 均值/20 divisor; the single calibration point for jitter spread.
- `computeDamageMean(attack, weaponRatio, weaponAttackRatio, deltaV): number` — computes the pre-jitter mean exactly as `Math.max(attack * weaponRatio * weaponAttackRatio * (Math.sqrt(clampedDeltaV) - 1), 0)`, where `clampedDeltaV` is `deltaV` coerced to `0` when it is not a finite number or is below 0 (so `Math.sqrt` never receives a negative or `NaN`). This is `D̄_R = max[A_A·P_A·W_A·(√Δv − 1), 0]` (research §Damage/Armor Formulas; PHYS-03).
- `rollDamage(rng: IRng, mean: number): number` — returns `sampleNormal(rng, mean, mean / DAMAGE_JITTER_SIGMA_DIVISOR)` (the spec's normal jitter, σ = mean/20). Do NOT write a new sampler — call the shared `sampleNormal` (AGENTS §9).
- `computeDamageReduction(damage, defense, armorRatio, armorDefenseRatio, penetration): number` — the armor reduction `ΔD`. Use the D-11 sign-consistent form: treat `B_A` as the penetration ratio itself (NOT its reciprocal) and return `damage * (1 - (100 * penetration) / (100 * penetration + defense * armorRatio * armorDefenseRatio))`. Guard the denominator: if it is not finite or is `0` (e.g. penetration 0 and all defense terms 0), return `0` so the result is always finite and non-negative. JSDoc must state the D-11 ruling explicitly (higher penetration bypasses more armor).
- `computeFinalDamage(damage, defense, armorRatio, armorDefenseRatio, penetration): number` — returns `damage - computeDamageReduction(damage, defense, armorRatio, armorDefenseRatio, penetration)` (the spec's `D = D_R − ΔD`).
- `isDamageBearingPair(partA: ColliderPart, partB: ColliderPart): boolean` — returns `true` iff exactly one of the two parts is `ColliderPart.Weapon` (i.e. `(partA === ColliderPart.Weapon) !== (partB === ColliderPart.Weapon)`). This encodes D-13/OQ-4: weapon↔body and weapon↔armor bear damage; body↔body and weapon↔weapon do not. JSDoc must note that the caller separately verifies the two colliders belong to different units.

Do NOT add: any Rapier import, a `PhysicsWorld`-style class, mutable module state, a new RNG abstraction, or the reciprocal `1/penetration` reading. Do not add a body-hit helper that returns `0` reduction — the caller uses `isDamageBearingPair` + the `defenderPart` to skip reduction on a body hit (D-11 击中本体不减伤).
  </action>
