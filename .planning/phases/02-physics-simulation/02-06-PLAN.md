  <action>
Extend the existing `tick()` in `src/physics/PhysicsWorld.ts` (do NOT rewrite the class or the contact logic from plan 02-05) to also emit damage events.

Pre-step snapshot: BEFORE `#world.step(#eventQueue)`, iterate `#bodies` and store each body's linear velocity (`linvel()`) into `#preVelocities` keyed by unit id. (This is the Δv source; reading velocities after the step is the documented bug — research Pitfall 6. A comment/limit note should say Δv is linear-only as the calibrated simplification per CONTEXT discretion / research A2.)

After the step, while building the contact list, additionally compute a damage event for each contact pair that is damage-bearing:
1. Use `isDamageBearingPair(tagA.part, tagB.part)` from `@/physics/damage` to decide; skip the pair otherwise (this excludes body↔body and weapon↔weapon, D-13/OQ-4).
2. Identify the weapon side as the attacker (its `unitId` → `attackerId`) and the other side as the defender (`defenderId`). Set `attackerPart` to that side's `ColliderPart.Weapon` and `defenderPart` to the defender tag's part (`Body` or `Armor`).
3. Fetch the world-space contact normal: `#world.contactPair(#world.getCollider(handle1), #world.getCollider(handle2), (manifold) => { const n = manifold.normal(); nx = n.x; ny = n.y; })`. Copy `n.x`/`n.y` into local numbers INSIDE the closure (the manifold is temporary — never retain it). If either collider no longer resolves, skip the damage event for that pair.
4. Compute `deltaV = |(vAttacker − vDefender) · n|` using the PRE-step velocities from `#preVelocities` (default both to 0 if absent). Coerce non-finite results to `0` so no `NaN`/`Infinity` propagates.
5. Look up the attacker's `IUnitPhysicsSpec` and its weapon def from `#specs` (the spec retains `attack`, `weaponRatio`, and `weapon`). Compute `damageMean = computeDamageMean(spec.attack, spec.weaponRatio, weapon.attackRatio, deltaV)`.
6. Roll the jitter: `rolled = rollDamage(#rng, damageMean)` (the shared σ = mean/20 jitter).
7. Resolve the defender's part:
   - If `defenderPart` is `ColliderPart.Armor`: `armorKind` is the defender tag's `armorKind` (bound per armor collider at registration, D-13/OQ-4). Find the defender's armor def whose `id === armorKind` in `defenderSpec.armors`; `penetration = weapon.penetration[armorKind]`; `reduction = computeDamageReduction(rolled, defenderSpec.defense, defenderSpec.armorRatio, armorDef.defenseRatio, penetration)`; `damage = rolled - reduction` (equivalently `computeFinalDamage`); `damageReduced = reduction`.
   - If `defenderPart` is `ColliderPart.Body`: `armorKind` is `undefined`, `damage = rolled`, `damageReduced = 0` (击中本体不减伤, D-11).
8. Push an `IDamageEvent` with `attackerId`, `defenderId`, `attackerPart`, `defenderPart`, `weaponKind` (the weapon def's id; `undefined` if the attacker had no weapon — which the damage-bearing check already excludes), optional `armorKind`, `deltaV`, `damageMean`, `damage`, `damageReduced`.

`tick()` returns `{ contacts, damages }`. Keep the arrays readonly. Do NOT touch any `Unit`, and do NOT move damage application into the physics layer (D-09/D-14 — the caller applies `takeDamage`/`gain*Experience`). Keep private members JSDoc'd; add no public member outside `IPhysicsWorld`.

| (no network / no secrets) | Headless in-process module; no I/O. |
