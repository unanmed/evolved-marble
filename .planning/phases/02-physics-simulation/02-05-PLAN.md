After the step, collect contacts:
1. Allocate an array of `IContactEvent`.
2. Call `#eventQueue.drainCollisionEvents((handle1, handle2, started) => { ... })`. The callback signature is exactly `(handle1: number, handle2: number, started: boolean) => void` — there is NO normal here (research Pitfall 2); do not attempt to read one.
3. Inside the callback: `if (!started) return;` (only `started` transitions, D-08).
4. Look up both handles in `#index`. If either handle is missing (e.g. a collider removed mid-flow), skip the pair.
5. Defensive same-unit guard: if both tags share the same `unitId`, skip the pair (Rapier's broad phase does not pair same-body colliders — research Pitfall 4 — so this should never fire, but the guard makes a self-contact impossible to surface).
6. Push an `IContactEvent` with `unitAId`/`partA` from the first tag and `unitBId`/`partB` from the second, preserving the drain's unordered A/B order (do NOT attribute attacker/defender here — that is plan 02-06).

`tick()` returns `{ contacts, damages: [] }` where `damages` stays empty in this plan (the damage layer is plan 02-06). Keep the `IContactEvent[]` array shape `readonly` in the returned `IPhysicsTickResult`.

Do NOT fetch contact normals here, do NOT snapshot velocities here, and do NOT compute damage here. Keep private members JSDoc'd; add no public member outside `IPhysicsWorld`.

|----------|-------------|
| engine events → typed events | Raw integer handle pairs from the `EventQueue` cross into the typed-event layer; a stale/unknown handle must not produce a mis-attributed event. |
| engine handle reuse | A handle can be reused after removal; the index lookup must reflect current ownership (established in plan 02-04). |
| (no network / no secrets) | Headless in-process module; no I/O. |
