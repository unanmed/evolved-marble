<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host pump → sim core | Only crossing into `sim/**`; must carry a step budget, never a wall-clock value. |
| seeded RNG → sim state | The sole permitted randomness source; any other source is a determinism (integrity) failure. |
| package build → sim boundary | `tsconfig.sim.json` (DOM-free) is the compiler half of the headless boundary. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Tampering | `src/sim/**` randomness/time sources | high | mitigate | All randomness through the seeded `RandomStreams` facade; no wall-clock read in `sim/**`; iteration only over `orderedIds` (Pitfall 4/5). Hard-linted in Plan 01-03. |
| T-01-03 | Spoofing | `fingerprint()` | low | accept | The hash is non-cryptographic and is documented in `snapshot.ts` as a diagnostic, never an authenticator (V6). No security decision will consume it. |
| T-01-SC | Tampering | `pnpm install` of toolchain | high | mitigate | Covered and human-verified in Plan 01-01 (Task 2); no new installs in this plan. |

**Phase posture:** no network, no persistence, no user input this phase. The only real integrity risk is nondeterministic input leaking into sim state (T-01-01).
</threat_model>
